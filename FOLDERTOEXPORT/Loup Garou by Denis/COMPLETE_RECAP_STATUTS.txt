🎮 COMMENT ÇA MARCHE:

1. STRUCTURE DU JOUEUR:
   ┌─────────────────────────────────────┐
   │ player = {                          │
   │   id: "player_123",                 │
   │   name: "Loris",                    │
   │   roleId: "Renard",                 │
   │   isDead: false,                    │
   │   statuses: {       // ← NOUVEAU    │
   │     "Amoureux": {                   │
   │       partner: "player_456"         │
   │     },                              │
   │     "Charmé": {                     │
   │       source: "player_789"          │
   │     }                               │
   │   }                                 │
   │ }                                   │
   └─────────────────────────────────────┘

2. AJOUTER UN STATUT:
   gm.addStatusToPlayer(lorisId, 'Amoureux', { partner: benoitId });
   ↓
   Loris reçoit le statut Amoureux avec Benoît comme partenaire

3. QUAND QUELQU'UN MEURT:
   statusHandler.onPlayerDeath(lorisId, 'vote');
   ↓
   • Si Loris a le statut Amoureux → Benoît meurt aussi IMMÉDIATEMENT
   • Si Loris est un Modèle → Son Enfant Sauvage devient Loup
   • Si Loris est Maire → Le Garde Champêtre devient Maire
   • etc.

4. ÉVÉNEMENTS SPÉCIAUX:
   • Cupidon: gm.createLovers(p1, p2) → Amoureux mutuels
   • Joueur Flûte: gm.charmPlayers(flute, [p1, p2, p3]) → Charmés
   • Enfant Sauvage: gm.setChildModel(enfant, model) → Modèle
   • Père des Loups: gm.infectPlayer(pere, cible) → Infecté
   • Vote: gm.electMayor(joueur) → Maire + 2 voix

🔗 INTÉGRATION DANS LE CODE:

Pour utiliser les statuts dans 03-FirstNight.js ou 04-FirstNight-Actions.js:

// Créer un handler
const statusHandler = new StatusesHandler(gm);

// Cupidon crée 2 amoureux
if (cupidoConfirmBtn.clicked) {
  const [p1, p2] = getSelectedPlayers();
  gm.createLovers(p1.id, p2.id);
  gameUI.render(); // Afficher les changements
}

// Quand quelqu'un meurt
function handlePlayerDeath(playerId) {
  statusHandler.onPlayerDeath(playerId, 'wolf');
  gameUI.render();
}

// Fin de nuit: vérifier victoire du Joueur de Flûte
function onNightEnd() {
  const winner = statusHandler.checkFluteWinCondition();
  if (winner) {
    displayWinScreen(winner);
    endGame();
  }
}

📝 EXEMPLES CONCRETS:

EXEMPLE 1: Cupidon (Nuit 1)
├─ Cupidon choisit Loris et Benoît
├─ gm.createLovers(lorisId, benoitId)
├─ Chat: "💕 Loris et Benoît sont maintenant Amoureux!"
└─ Jour 3: Loris meurt au vote
   ├─ statusHandler.onPlayerDeath(lorisId, 'vote')
   ├─ Chat: "💔 Benoît meurt aussi car amoureux de Loris!"
   └─ Benoît meurt IMMÉDIATEMENT

EXEMPLE 2: Joueur de Flûte (Nuit 3-5)
├─ Flûte charme 5 joueurs une à une
├─ gm.charmPlayers(fluteId, [p1, p2, p3, p4, p5])
├─ Chat: "🎶 Joueur de Flûte charme joueur1 et joueur2 et..."
├─ Fin nuit 5: statusHandler.checkFluteWinCondition()
├─ Chat: "🎵 VICTOIRE JOUEUR DE FLÛTE!"
└─ La partie s'arrête

EXEMPLE 3: Enfant Sauvage
├─ Nuit 1: Enfant choisit Idole = Alice
├─ gm.setChildModel(enfantId, aliceId)
├─ Chat: "⭐ Enfant a choisi Alice comme idole"
├─ Nuit 2: Loups tuent Alice
├─ statusHandler.onPlayerDeath(aliceId, 'wolf')
├─ Chat: "🐺 Enfant devient un Loup-Garou!"
└─ Enfant change de rôle et rejoint les Loups

EXEMPLE 4: Père des Loups
├─ Nuit 1: Père infecte un Villageois
├─ gm.infectPlayer(pereId, villageoisId)
├─ Chat: "🐺 Père des Loups infecte Villageois - devient Loup!"
└─ Villageois change immédiatement de rôle et camp

EXEMPLE 5: Élection du Maire
├─ Jour 1: Vote du village élit Gaëlle
├─ gm.electMayor(guelleId)
├─ Chat: "👑 Gaëlle est élue Maire! (2 voix au vote)"
├─ Jour 2+: Gaëlle a 2 voix au lieu de 1
└─ Si Gaëlle meurt: Garde Champêtre devient Maire
