# 🌙 ORDRE LINÉAIRE DE LA PREMIÈRE NUIT - 39 RÔLES

## Ordre d'Assignation des Rôles - Maître du Jeu

Cet ordre suit la logique réelle du Loup-Garou:
1. **Rôles critiques** (définissent le jeu)
2. **Actions de jour spéciales** (affectent le vote)
3. **Actions nocturnes** (pouvoirs la nuit)
4. **Rôles spéciaux** (liaisons, protections)
5. **Loups** (se connaissent)
6. **Passifs** (juste pour noter qui c'est)

## 💡 Comment Utiliser

1. **Première Nuit**: Appelez les rôles dans cet ordre EXACT
2. **Chaque Nuit Suivante**: Même ordre pour cohérence
3. **Au Jour**: Tous les villageois vivants votent
4. **Fin Partie**: Loups gagnent si ≥ villageois vivants; Villageois gagnent si 0 loup
