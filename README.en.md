# 🎲 SoundBoardHTMLMaker

🇫🇷 [Version française](README.md)

**Build your board game's companion interface, no coding required.** Ambience, sound effects and, if you want, your own tools (rules, a game assistant…). It all lives in a web page that works on PC, tablet and phone, even offline.

Drop your mp3 files in a folder, arrange everything in the editor, export. That's it.

👉 **Demo:** [soaresden.github.io/SoundBoardHTMLMaker](https://soaresden.github.io/SoundBoardHTMLMaker/)

The interface switches between **English and French** (🇬🇧 / 🇫🇷 button, or automatically from your browser language).

## ✨ What you get

| The player (tablet, PC or phone) | The editor (on your PC) |
|---|---|
| ![Metal Gear player](docs/img/player-metal-gear.png) | ![Editor](docs/img/editeur.png) |

- **Looping ambient music**, sorted into categories, with cover art (read from the mp3 tags).
- **One-tap sound effects**, with per-sound and master volume.
- **MP3 or WAV**: a `.wav` dropped into `music/` or `sfx/` is converted to `.mp3` automatically on Scan and Build. The original stays on your PC and is never published.
- **Your own theme**: two colors, or picked automatically from a cover.
- **Web editor**: drag and drop, categories, titles, volumes, without touching the code.
- **Offline**: a button (or auto mode) caches every sound on the tablet.
- **Two export formats**:
  - **Light**: an `index.html` + the sound folders. Ideal for GitHub Pages.
  - **All-in-one**: a single HTML file containing everything, to copy anywhere.
- **Extensible**: each game can add its own buttons, pages and scripts. See the examples.

## 🚀 Quick start (Windows)

**You need:** [Python 3](https://www.python.org/downloads/), with *“Add Python to PATH”* checked during install.

1. Download the project (green **Code → Download ZIP** button, or `git clone`).
2. Double-click **`runme.bat`**. It installs what's needed and opens the menu.
3. Pick **[7] New game** and name it (e.g. *“Dixit at Paul's”*). This creates `games/dixit-at-pauls/`.
4. Put your music in that folder's `music/` and your sound effects in `sfx/`.
5. **[1] Scan** to read your mp3s, then **[2] Editor** to sort, rename and color.
6. **[3] Build**: your soundboard opens, ready to play. It's in `FOLDERTOEXPORT/dixit-at-pauls/`.

> Not on Windows? Everything works from the command line too (`python build.py …`, see below), and the editor starts with `python server_static.py`.

## 📱 Getting it on your tablet

**Easiest: GitHub Pages** (free, a web address to open on the tablet).

1. *Fork* this repository (or push your own to GitHub).
2. On GitHub: **Settings → Pages → Branch: `main` / `(root)`**.
3. After a build and a `git push`, your game is online:
   `https://<your-username>.github.io/<repo>/FOLDERTOEXPORT/<your-game>/`
   The home page `https://<your-username>.github.io/<repo>/` lists all your games.
4. On the tablet, open the page and tap **📥 Offline**: every sound is cached and it then works with no network. Tip: “Add to Home Screen”.

**No internet:** copy `FOLDERTOEXPORT/<your-game>/` to the tablet and open `index.html`. Or make an **All-in-one** build ([4]) and copy just `index_aio.html`.

## 🗂️ How it's organized

```
games/                      ← YOUR GAMES (sources, this is where you work)
  _template/                ← the template copied by “New game”
  my-game/
    config.json             ← sounds, categories, options (filled by Scan + Editor)
    music/  sfx/            ← your mp3s
    covers/                 ← cover art (extracted automatically on Scan)
    inject/                 ← (optional) HTML added to the player
    extras/                 ← (optional) files copied as-is into the export
FOLDERTOEXPORT/my-game/     ← GENERATED by the build: publish / copy it, never edit it
index.html                  ← generated home page (list of games, for GitHub Pages)
templates/                  ← the player, editor and offline mode shared by every game
build.py · runme.bat        ← the tools
```

**Golden rule:** edit `games/`, never `FOLDERTOEXPORT/`. The build regenerates the export and only deletes files **it created itself**: a folder you add to the export yourself (an Android app, PDFs…) is never erased.

### Game options (`config.json` → `project`)

| Key | Role | Example |
|---|---|---|
| `name` | Displayed name | `"Werewolf 🐺"` |
| `themeColor`, `themeColor2` | The theme's 2 colors (also set in the editor) | `"#5b8cff"`, `"#8a5cff"` |
| `description` / `description_en` | Text on the home page (French / English) | `"Ambience for…"` |
| `offline` | `"button"` = 📥 Offline button · `"auto"` = automatic caching · missing = off | `"button"` |
| `versionSwitch` | Shows the Light / All-in-one switch button | `true` |
| `links` | Extra links on the home page (`title`, `title_en`, `href`) | `[{"title": "📖 Rules", "href": "rules.html"}]` |

### Going further: `inject/` and `extras/`

To add your own tools to the player without touching the shared template:

| File | Where it's inserted |
|---|---|
| `inject/head-start.html` | in `<head>`, before the player styles |
| `inject/head.html` | in `<head>`, after the styles (to override them) |
| `inject/header.html` | header buttons, next to “Stop all” |
| `inject/body.html` | right before `</body>` (your scripts) |

Everything in `extras/` (scripts, images, HTML pages…) is copied as-is into the export. To make those files available offline too, declare them in `inject/body.html`:

```html
<script> window.SB_OFFLINE_EXTRA_URLS = () => ["rules.html", "img/board.jpg"]; </script>
```

Your scripts can also **drive the soundboard**:

```js
SB.playMusic("night-ambience.mp3");   // plays a track (from music/)
SB.playSfx("door.mp3");               // plays a sound effect (from sfx/)
SB.stopMusic();  SB.stopAll();  SB.current();
```

Static HTML in the template can be translated with `data-en="English text"` (and `data-en-title`, `data-en-ph` for tooltips and placeholders); scripts can use `SBT('Français', 'English')`.

### 🐺 Werewolf (Loup-Garou): soundboard + full Game Master

### 🐍 Metal Gear Solid: The Board Game
The game's music and voices, plus everything you need to play without mistakes:
- **🎮 Game assistant** — pick a mission, then:
  - **Briefing** with a Codec-style typed briefing, players, objective and failure conditions;
  - **Rules**: special rules, events, boss, errata and official FAQ answers built in;
  - **Board & setup**: the mission map reproduced square by square (Stage 1 and Stage 6 so far), pieces placed as in the book, setup checklist, and your **equipment** (starting gear + the 32 Memory Box cards, shared by the group);
  - **Play**: guided turns (“Your turn, Snake”), action points, tap-to-move with footsteps, line of sight and camera checks, actions greyed out when impossible, card-driven weapons and items (ammo, suppressors, Rations…), dice entry with results computed for you, guided enemy phase where each Guard's move is computed and animated, automatic alert music, and a 📞 **Codec** lookup;
  - **Debrief**: timed game log, end-of-mission stats and rank.
- **❓ Animated help**: 14 short scenes showing pieces moving (line of sight, noise, alert, cameras…), almost no text.
- **📖 Guide**: interactive lessons, the 14 campaign missions and VR Mission 60, the FAQ and errata v1.2.

Touch-friendly on tablets: landscape, no scrolling, pinch to zoom and drag the map with your fingers.

## ⌨️ Command line

```bash
python build.py list                 # list games (★ = current game)
python build.py use metal-gear       # choose the current game
python build.py new "My game"        # create games/my-game/ from the template
python build.py scan [game]          # read mp3s -> config.json (your settings are kept)
python build.py build [game]         # Light export
python build.py portable [game]      # All-in-one export (single file)
python build.py all [game]           # both
python build.py build-all            # every game + home page
python server_static.py --game my-game   # editor at http://127.0.0.1:8765/editor
```
